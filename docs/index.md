# Ursina For Mobile

### The new era of ursina
Did you ever wanted to export your ursina game for android? Now you can, with this project!

Currently, **only Android is supported**. iOS support is unlikely at this time because Panda3D does not officially support building for iOS out-of-the-box, and testing hardware is limited.

---

## I want to port my game for android
To do that, follow this documentation. Everything you need to know about setting up your environment, structuring your game, and building your APKs/AABs is right here.

## I need help
If you need help or if anything doesn't work, you can create an [issue](https://github.com/PaologGithub/UrsinaForMobile/issues) or start a new [discussion](https://github.com/PaologGithub/UrsinaForMobile/discussions) on the main repository.

Since errors can also be Ursina-related, feel free to join the [Ursina Engine Discord](https://discord.com/invite/ydXfhyb) where the community (and I!) can help out.

## Contributing
If you want to participate in the new era of Ursina:

* You can improve this project by submitting a [pull request](https://github.com/PaologGithub/UrsinaForMobile/pulls).
* If you find a bug, please make an [issue](https://github.com/PaologGithub/UrsinaForMobile/issues).
* You can also help the main engine by doing pull requests or issues on the [Ursina GitHub](https://github.com/pokepetter/ursina).
