# Installation

To start building your game, you need the UrsinaForMobile project repository. This project contains the predefined folder structure and build scripts required to package an Ursina game for Android.

## Getting the Project

You can download or clone the project directly from the main repository tree:

UrsinaForMobile Main Repository

1. Download the repository as a ZIP file or clone it using Git:

   **Windows**
   ```cmd
   git clone https://github.com/PaologGithub/UrsinaForMobile.git
   ```
   **Linux**
   ```bash
   git clone https://github.com/PaologGithub/UrsinaForMobile.git
   ```
   **macOS**
   ```bash
   git clone https://github.com/PaologGithub/UrsinaForMobile.git
   ```
2. Navigate into the cloned folder.
3. Open your terminal or command prompt in this directory.
