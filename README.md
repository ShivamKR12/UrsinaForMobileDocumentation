# UrsinaForMobile Documentation

This repository contains the official documentation for **UrsinaForMobile** (UfM), a project that allows you to export your [Ursina Engine](https://github.com/pokepetter/ursina) games to Android.

🌍 **[Read the Documentation Here](https://shivamkr12.github.io/ursinaformobiledocumentation/)**

---

## Running Locally

This documentation is built using [MkDocs](https://www.mkdocs.org/) and the [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme.

To preview the documentation on your local machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/ShivamKR12/UrsinaForMobileDocumentation.git
   cd UrsinaForMobileDocumentation
   ```
2. Install the required dependencies (preferably in a virtual environment):
   ```bash
   pip install mkdocs-material
   ```
3. Start the local development server:
   ```bash
   mkdocs serve
   ```
4. Open `http://127.0.0.1:8000` in your web browser.

## Contributing

Contributions to the documentation are welcome! 

* All documentation content is written in Markdown and lives inside the `docs/` folder.
* The navigation and site configuration are handled in `mkdocs.yml`.
* When you push to the `main` branch, a GitHub Action will automatically build and deploy the updated site to GitHub Pages.
